# Architecture Decision Records

Short documents that capture an important decision, the context behind it, and the alternatives that were
rejected. See [ADR 1](0001-record-architecture-decisions.md) for the format and when to write one.

To add one: copy [`0000-template.md`](0000-template.md) to `NNNN-short-title.md` (next free number), fill it
in, and add it to the table below.

| ADR | Title | Status |
|---|---|---|
| [0001](0001-record-architecture-decisions.md) | Record architecture decisions | Accepted |
